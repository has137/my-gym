# My gym

نسخة شخصية غير تجارية من [openGym](https://github.com/DuarteSantos8/openGym)، مبنية لبرنامج
تمرين منزلي بالعربية: قوة وشكل V، ملاكمة وحبل، وحماية المفاصل وتأهيل الكاحل.

| الشيء | أين |
|---|---|
| التطبيق | <https://has137.github.io/my-gym/> |
| الكود | <https://github.com/has137/my-gym> |
| البرنامج المعتمد | [program.md](program.md) |
| البحث والمصادر | [research.md](research.md) |
| الأصل | openGym 1.4.2، الترخيص AGPL-3.0-or-later |

## التثبيت على الآيفون

| الخطوة | ماذا تفعل |
|---|---|
| 1 | افتح الرابط في Safari (ليس في متصفح آخر) |
| 2 | اضغط زر المشاركة أسفل الشاشة |
| 3 | اختر «إضافة إلى الشاشة الرئيسية» |
| 4 | اضغط «إضافة». يفتح التطبيق بعدها بملء الشاشة، ويعمل بلا إنترنت بعد أول فتح |

بياناتك تبقى على الجوال فقط، داخل التطبيق المثبّت. لا حساب ولا خادم.

## النسخة الاحتياطية والاستعادة

| العملية | الطريقة |
|---|---|
| أخذ نسخة | كل 7 أيام تظهر بطاقة «خذ نسخة احتياطية» في صفحة اليوم. اضغط «احفظ نسخة الآن» واحفظ الملف في «الملفات» أو iCloud Drive |
| أخذ نسخة يدوياً | الإعدادات ← البيانات والنسخ الاحتياطي ← تصدير نسخة احتياطية (JSON) |
| الاستعادة | الإعدادات ← البيانات والنسخ الاحتياطي ← استيراد نسخة احتياطية، ثم اختر الملف. تحلّ النسخة محل كل البيانات الحالية |

اسم الملف: `mygym-backup-YYYY-MM-DD.json`. احذف التطبيق من الشاشة الرئيسية أو امسح بيانات Safari
وتضيع البيانات، فلا تفعل ذلك قبل أخذ نسخة.

## ما في التطبيق

| الشاشة | ما فيها |
|---|---|
| أول استخدام | تنبيه أنه ليس بديلاً عن الطبيب، 7 أسئلة صحية مبنية على موضوعات PAR-Q+، ونقطة البداية (العقلة، الضغط، الكاحل). تُعاد الأسئلة بعد سنة |
| اليوم | الجلسة المقترحة حسب الدور A ← B ← C ← D، والتزام الأسبوع، وأيام البرنامج، والنشاط الحر بضغطتين، وتذكير النسخة الاحتياطية، وموعد الاختبارات، وعلامة التخفيف المبكر |
| الجلسة | الإحماء وحماية المفاصل، وتمارين الكاحل حسب مرحلتك، والملاكمة ودرس الأسبوع، وتمارين المقاومة، وما تفعله في الراحة، والختام والإطالة |
| التمرين | شاشة openGym نفسها: المجموعات، والراحة، والتبديل من البدائل، وإضافة مجموعة. وعند الخروج يبقى شريط صغير يعيدك للجلسة |
| مؤقت الجولات | ملاكمة وحبل ودائرة النزال: أحمر للعمل وأزرق للراحة، ويقول المستوى القادم بعد الحفظ |
| المكتبة | تمارين openGym، و14 درس ملاكمة بالترتيب مع فائدة كل درس في الحلبة وفي الدفاع عن النفس |
| التقدّم | الأسبوع والمرحلة، والسلالم، ومتوسط الوزن الأسبوعي، والخصر، والاختبارات الدورية، والتخفيف المبكر، وحجم العضلات الأسبوعي |
| المفاصل | تسجيل الألم من 0 إلى 10 لكل مفصل، وقاعدة الألم، ومراحل الكاحل الأربع واختباراتها، وعلامات التوقف، وخطة الحماية |

## كيف يقرر التطبيق ما بعده

| الحالة | الاقتراح التالي |
|---|---|
| أكملت كل المجموعات في الحد الأعلى | الدمبل التالي من أوزانك (2 كغ أكثر)، والعودة لأسفل المدى |
| جلسة ناقصة أو مجموعات لم تكتمل | نفس الوزن، والدور ينتقل للجلسة التالية |
| تبديل تمرين أو إضافة مجموعة | لهذه الجلسة فقط، والخطة تبقى كما هي |
| وزن الجسم أو الشريط | تكرار واحد أكثر بعد كل جلسة نظيفة، ثم درجة أصعب في السلّم بعد جلستين في الحد الأعلى |
| الملاكمة في مرحلة الأساس | تثبت على 3 جولات × 2 د، وتزيد صعوبة التركيبة |
| الملاكمة بعدها | جولة إضافية، ثم الجولة أطول 30 ث |
| ألم 4 أو أكثر في آخر جلستين | يقترح تخفيفاً مبكراً لسبعة أيام |
| انقطاع | يخفف الأوزان والمجموعات حسب طول الانقطاع |

## التشغيل على جهازك (للتطوير)

```bash
cd frontend
npm install
npm run dev                         # http://localhost:5173 مع الخادم إن وُجد
VITE_STANDALONE=1 npm run build     # نفس نسخة GitHub Pages، بلا خادم
npx vitest run src/mygym            # اختبارات My gym وحدها
npm test                            # كل اختبارات الواجهة
```

النشر تلقائي: كل دفع إلى `main` يشغّل `.github/workflows/pages.yml`. يحتاج ذلك مرة واحدة:

| الإعداد | أين |
|---|---|
| تفعيل الـ Actions في الـ fork | تبويب Actions ← «I understand my workflows, go ahead and enable them» |
| مصدر GitHub Pages | Settings ← Pages ← Source: GitHub Actions |

## أين الكود

| المسار | ما فيه |
|---|---|
| `frontend/src/mygym/program/` | بيانات البرنامج (الجلسات، السلالم، بوابات الكاحل) وتحويلها إلى روتينات openGym |
| `frontend/src/mygym/lib/` | القرارات كدوال نقية مع اختباراتها: الكاحل، المراحل والتخفيف، السلالم، الانقطاع، الجولات والحبل، الألم، النشاط الحر، الجاهزية، الاختبارات |
| `frontend/src/mygym/content/` | دروس الملاكمة |
| `frontend/src/mygym/views/` و`components/` | الشاشات وشريط التبويب والشريط الصغير |
| `frontend/src/mygym/theme.css` و`fonts/` | تصميم Ring Night فوق متغيرات openGym، وخطا Changa وIBM Plex Sans Arabic |
| `frontend/src/mygym/i18n.js` | نصوص My gym بالعربية والإنجليزية، منفصلة عن ملفات لغات openGym |

ملفات openGym التي لمستها النسخة، وكل سطر فيها معلّم بـ «My gym»:

| الملف | التغيير |
|---|---|
| `frontend/src/App.jsx` | مسارات My gym وشريطها الصغير وأول استخدام |
| `frontend/src/components/TabBar.jsx` | شريط التبويب الخماسي |
| `frontend/src/store/useStore.js` | الإعدادات الأولى (العربية، الأحمر) والتشغيل بلا خادم |
| `frontend/src/lib/demo.js` و`components/SyncBanner.jsx` | وضع `VITE_STANDALONE` |
| `frontend/src/views/Settings.jsx` | رابط الكود، وختم النسخة الاحتياطية، وقسم «هذا الهاتف» |
| `frontend/index.html` و`public/manifest.json` | الاسم واللغة والاتجاه والألوان |
| `frontend/vite.config.js` | اختبارات openGym تعمل على openGym الأصلي (`VITE_MYGYM=0`) |
| `web/Dockerfile` | بصمة السكربت المضمّن في سياسة CSP |
| `.github/workflows/` | النشر إلى Pages، وإيقاف بناء الصور وiOS في الـ fork |
| `README.md` و`NOTICE.md` | إشعار النسخة المعدّلة والخطوط |

## التحديث من openGym

| الخطوة | ماذا تفعل |
|---|---|
| 1 | في صفحة الـ fork على GitHub اضغط «Sync fork». إذا ظهر تعارض، حلّه محلياً كما في الخطوات التالية |
| 2 | محلياً: `git fetch upstream` ثم `git merge upstream/main` |
| 3 | التعارضات تكون فقط في الملفات المذكورة أعلاه. احتفظ بأسطر «My gym» وبتغييرات openGym معاً |
| 4 | شغّل `cd frontend && npm test` واختبار الكتالوج `npx vitest run src/mygym/program/program.test.js`. إذا حذف openGym تمريناً أو غيّر معرّفه، يفشل هذا الاختبار ويسمّيه، ويستعمل التطبيق البديل الأول تلقائياً حتى تختار غيره |
| 5 | ادفع إلى `main`، فينشر GitHub Pages النسخة الجديدة |

| الحالة | الجزء |

| بُني | البرنامج كروتينات openGym مع الدور، ودروس الملاكمة، ومؤقت الجولات والحبل والدائرة، وصحة المفاصل ومراحل الكاحل، والنشاط الحر، وأسئلة الجاهزية، والاختبارات الدورية، والتخفيف (في موعده ومبكراً)، والعودة بعد انقطاع، وتذكير النسخة الاحتياطية، والتصميم بالوضعين الفاتح والداكن |

| لم يُبنَ | اكتشاف التراجع والنوم والجهد آلياً للتخفيف المبكر؛ تختاره يدوياً من «التقدّم»، والألم وحده يُكتشف آلياً |

## الترخيص، وما يمنع البيع لاحقاً

| الجزء | الوضع | أثره على البيع |
|---|---|---|
| كود openGym وكود My gym | AGPL-3.0-or-later | البيع مسموح، لكن من يستلم التطبيق أو يستعمله عبر الشبكة له حق الحصول على الكود كاملاً بنفس الترخيص |
| رسوم التمارين | ملك Gym visual، مرخّصة لـ openGym، خارج AGPL | تمنع البيع. أي نسخة تجارية تحتاج ترخيصاً خاصاً من gymvisual.com أو رسوماً بديلة |
| استثناء متاجر التطبيقات | لصاحب openGym فقط | لا يغطي نسخة معدّلة. النشر في App Store يحتاج إذناً منه أو كوداً لا يملكه |
| اسم openGym وشعاره | لصاحب المشروع | لا تبع باسمه. «My gym» اسم عام قد يكون مسجلاً لغيرك؛ ابحث قبل البيع |
| الخطوط | SIL OFL 1.1 | تسمح بالبيع مع التطبيق، ولا تسمح ببيع الخطوط وحدها |
| نصوص الكتالوج | جزء منها MIT (من ExerciseDB)، والباقي AGPL | لا يمنع البيع، مع إبقاء إشعار MIT وشروط AGPL |
